# Python 与并发面试八股

## 一、Python 基础

### 1）Python的B库是什么
"Python的B库"这个说法并不严格，面试里更常见的真实意思通常是Python标准库，或者有人把Python的 Batteries Included 理念口语化地说成了B库。它指的是安装Python之后不需要额外安装就能直接使用的一批内置模块，比如操作文件和目录的模块、处理JSON的模块、时间日期模块、正则表达式模块、线程和异步相关模块等。更准确的回答应该是，Python有很丰富的标准库，因此很多基础功能开箱即用，这也是Python工程效率高的重要原因。

## 二、并发模型

### 2）什么是进程
进程可以理解为操作系统中一个正在运行的程序实例，它是系统分配资源的基本单位。每个进程通常拥有独立的地址空间和资源上下文，因此进程之间天然隔离，一个进程出问题通常不会直接破坏另一个进程的内存状态。由于创建和切换进程的成本相对较高，所以进程通常更适合做相互独立、计算量较大或者需要真正并行执行的任务，在Python里也常被用于绕过GIL去处理CPU密集型工作。

### 3）什么是协程
协程是一种由程序自身控制调度的轻量级并发单元，它不是由操作系统像线程和进程那样直接抢占式调度，而是由事件循环在合适的等待点进行切换。协程最适合处理网络请求、数据库访问、文件IO这类等待时间长但单次计算不重的任务，因为在一个协程等待外部结果时，程序可以立即切换去执行别的协程，从而显著提升整体吞吐。简单说，协程的核心价值不在于"并行算得更快"，而在于"等待时不浪费时间"。

### 4）进程和协程的区别
进程和协程最大的区别在于调度方式、资源隔离和适用场景。进程由操作系统调度，拥有独立内存空间，隔离性强但开销大，适合CPU密集型任务或强隔离场景；协程由程序在用户态调度，切换成本很低，多个协程通常共享同一进程内资源，更适合高并发的IO密集型任务。面试时可以用一句话概括：进程更像重量级并行单位，协程更像轻量级高并发单位。
